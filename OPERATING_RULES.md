# Operating rules

1. After every user-supplied match/transfer/development screenshot, update only affected files.
2. Game facts outrank story assumptions.
3. World metrics persist once introduced.
4. Show previous → current for every active metric when a tracker is shown.
5. New metrics may start with previous = null; after first change they must have both values.
6. Preserve conflicts in conflicts.json rather than silently rewriting history.
7. Keep match-mode recommendation separate from outcome prediction.
8. Never force a storyline because a metric exists; metrics react to football.
9. Rare off-pitch events should remain rare enough to feel meaningful.
10. The save remains 70/20/10: normal football / substantial story / cinema.
